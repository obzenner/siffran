## A. Generic module (`lib/obligations`) — revision required before Lane B/C write

| # | Decision | Resolves |
|---|---|---|
| A1 | **No persisted `state` on `Obligation`.** Status is *derived* by `verify()` — the same principle Empirica applies to claims (SKILL.md "Derived claim state … there is no persisted state field"). Replace `state` with an optional caller-declared `hold: None \| "blocked" \| "deferred"` + `hold_reason: str \| None` (analogue of Empirica's `blocked:` tags: a declaration that the actor cannot currently discharge it, never a claim that it *is* discharged). | Sol's `state` vs `status` double source of truth |
| A2 | **Split requirement from prohibition.** `Obligation.mode: "require" \| "forbid"`. Remove `must_not`. A `forbid` obligation's `must` text states the forbidden effect; its witnesses describe how that effect would be *observed*. Verify: `forbid` + any witness observed at its `expect` → `violated`; otherwise `holds`. `require`: all witnesses observed at `expect` → `satisfied`; any observed at the opposite outcome → `violated`; else `residual`. The issue's O17 becomes two obligations. | Sol's verifier conflates must/must_not witnesses on one obligation; must_not could never be satisfied (GLM F7) |
| A3 | **Verdict partitions:** `satisfied, holds, violated, residual, unwitnessed (⊆ residual), held (⊆ residual: residual obligations carrying a hold tag)`. Deterministic, sorted by id. | A1/A2 |
| A4 | **`Witness{kind, ref, expect: pass\|fail, description: str}`** — `description` is the human-readable discharge condition (required, non-empty). `expect` stays machine-matchable. | Terra used `expect` for prose; Sol for outcome — both were right about something |
| A5 | **Canonical `ref` grammar**, enforced at construction and in the schema: `^[a-z][a-z0-9_-]*(/[A-Za-z0-9._:@-]+)+$` (a lowercase namespace, one or more `/segments`, no whitespace, case-sensitive). Examples: `research/G7`, `spike/G7`, `audit/3f9a…`, `decision/G4`, `budget/run`. | GLM D2 ref-grammar divergence |
| A6 | **`Observation.source` required non-empty for every kind**; for `kind == "judgment"` additionally reject `anonymous`/`unknown`/`model` (case-insensitive) at construction. Trust stays injected. | GLM D3 anonymous judgment |
| A7 | **Honest revisions.** `revise(contract, *, add=(), retire=(), reason: str, authority: str) -> Contract`. `retire` (ids) requires non-empty `reason` and `authority`; retired obligations are kept on the contract as `retired: tuple[Retirement{obligation, reason, authority, at_revision}]` — never silently absent. Ids are unique across live + retired. `revision` increments, `parent_revision` and `supersedes` set as Sol has them. The module records authority; *policy* about who may revise is the caller's (Empirica: never the executing actor alone — Lane B writes that rule down in ADR-0039). | GLM D4 goalposts |
| A8 | **Canonical decoder + normal form.** `canonical(contract) -> dict` (sorted obligations, sorted witnesses, `must` whitespace-collapsed) and `parse(view) -> Contract` (inverse of `project` for the contract part). `preserved(before_view, after_view) -> Preservation{ok: bool, reasons: tuple[str, ...]}` is defined as: for every obligation in `parse(before)`: present in `parse(after)` **or** listed in `after.retired` with reason; `mode` equal; `must` equal after normalisation; `witnesses(before) ⊆ witnesses(after)` (witnesses may be added, never removed — DbC "never weaken"); `because(before) ⊆ because(after)`. "Less specific" is thereby defined as *text change or witness loss*; the module claims nothing about semantic specificity and its docstring says so. | GLM D5/F2/U9 decidability |
| A9 | **Per-witness observation in the view.** `project(contract, verdict, observations?)` emits for each witness `observed: "pass" \| "fail" \| null` so a cold-start agent sees *which* fold is done (Fold 1 done, Fold 2 missing) without a `partial` state. | Terra B-3 partial state |
| A10 | **One text renderer in the lib.** `render_text(view) -> str`: deterministic, every obligation id, mode, must, hold, and every witness `kind:ref (expect) — description [observed]`; fixture pins the exact string so the TS mirror cannot drift. Adapters that only have a string channel (Claude stderr, Codex deny reason, Pi notices) call this; they never hand-format. | GLM D1 transport flattening |
| A11 | **Fixtures = GLM's F1–F15**, executable shape: `{"name", "contract", "observations", "trusted_sources", "expect": {"verdict": …, "view": …, "text": …}}`, plus preservation fixtures `{"before", "after", "expect": {"ok", "reasons"}}`, plus one revision fixture and one cold-start round-trip (`parse(project(c)) == canonical(c)`). Delete Sol's six or fold them in. Python and TS tests iterate the fixture directory; adding a fixture must require zero test code. | GLM D6 |
| A12 | `scripts/validate_obligations.py` must validate fixture *instances* against the schemas. If `jsonschema` is absent, implement the minimal structural check in stdlib (required keys, enums, ref regex) rather than skipping — a validator that silently degrades is not a gate. | Sol residual risk; Terra B-4 |
| A13 | Public API (frozen after Sol's revision): `Witness, Obligation, Observation, Contract, Retirement, Verdict, Preservation, verify, revise, project, parse, canonical, preserved, render_text, to_json/from_json` for each value. Docstring header lists what the module does not know (unchanged). | Lane B/C need a frozen import surface |

## B. Empirica consumption (Lane B) — shape decisions

| # | Decision | Resolves |
|---|---|---|
| B1 | **One location on the wire: `run.contract`** = the `project()` view, in all three cases (Block, RestoreRun Allow, terminal Allow). Counts stay in `snapshot.graph` as telemetry. Terminal Allow additionally carries `run.contract_artifact_id`. Consumers read exactly one path. | Terra proposed three placements; Luna asked for consistency |
| B2 | **Projection traverses the graph**, never `Block.open_claims` (capped at 10). `ClaimReason` remains for the prose `reason`. | Terra residual risk 1 |
| B3 | **Empirica supplies a Contract + Observations; the lib computes status.** Witness refs per Terra's table with `expect: "pass"`: `artifact research/<id>` (every claim), `exit_code spike/<id>` (`needs-experiment`), `judgment audit/<argument_digest>` (run-level, `because` = approved claim ids, `source` = auditor model from the ticket), `judgment decision/<id>` (`needs-decision`, hold=blocked), `event budget/<id>` (`needs-budget`, hold=blocked), `event budget/run` (synthetic, spawn/pass cap), `event resume/<handle>` (synthetic, stall). Observations come from evidence leaves / spike records / audit verdicts via a pure helper over `Knowledge.evidence_leaves` — **no regex over reason strings**. Deferred claims (frozen scope) get `hold=deferred`. | Terra B-3, GLM D3 (machine facts get machine kinds) |
| B4 | **`trusted` predicate** for Empirica: an observation is trusted iff its `source` is one of: the spike harness (`exit_code`), the knowledge store (`artifact`), the audit ticket's dispatcher-recorded model (`judgment audit/*`), the human (`judgment decision/*`), the operator (`event budget/*`). Never the executing model. | GLM D3 |
| B5 | **Persist the contract revision as an `Artifact`** whenever the obligation *set* changes (new claim → `revise(add=…)`; refuted claim → `retire(reason="refuted by <evidence id>", authority="evidence")`) and on terminal Allow. Verify the `ArtifactRepository` envelope first (Terra flagged UNVERIFIED). | GLM D1 durable carrier; issue §5 |
| B6 | **Revision authority rule (ADR-0039):** the run's contract may be revised only by the application in response to a knowledge artifact (claim graph write, refutation, freeze) — never by a bare request. Record `authority` as the artifact id that caused it. | GLM D4 |
| B7 | Tests exactly as Terra B-5 (1–5), with `preserved()` at every hop and the mutation test that fails when `run.contract` is dropped; RS2 extended, not replaced. Claude stderr = prose + `render_text(view)`; Codex deny/system message likewise; Claude/Codex restore already embed the snapshot → add a test that the embedded JSON `parse()`s back to the same canonical contract. | Terra B-5 |
| B8 | Schema: add `$defs.contract_view` to `contracts/empirica/v1/response.schema.json` by `$ref` to `../../obligations/v1/contract.schema.json#/$defs/view` (keep additionalProperties); new fixtures per Terra B-4; `scripts/validate_contracts.py` gains instance validation (share the stdlib checker from A12). | Terra B-4 |
